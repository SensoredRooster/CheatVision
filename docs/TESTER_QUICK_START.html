CHEATVISION · VOD TESTER

How-to · Warzone · Long VODs and short clips

Offline helper · live pipeline unchanged
Goal: Drop a labeled video, type the watched player’s tag, and let CheatVision cut reviewable kill clips. This does not change live detection or the main model.

1 · Start, then drop

  1. Double-click watch_vod_inbox.bat and leave it open.
  2. Start the watcher before copying videos. It only notices new files.
  3. When the copy finishes, enter the watched player’s exact in-game tag in the popup.
  4. The original video stays in the inbox. Review extracted clips before sharing.

2 · Where the video goes = the label

Drop the video here Use when Clips are saved as
data\vod_inbox\clean\ You have verified the footage is clean. data\vod_dataset\clean\
data\vod_inbox\cheating\ You have confirmed the kills are cheating. data\vod_dataset\suspicious\

Do not mix unverified footage. Folder choice is the label. What it reads: bottom-left HUD (player) → middle-left kill feed (that player as killer) → mid-right elimination toast (fallback).

Long VOD

Scans the whole recording. Default clip is 10 sec before and 4 sec after each distinct kill.

Best for 5+ minute matches. One file can produce several clips.

Short clip

Same scan. Uses whatever footage is in the file if a full 14-second window is not available.

If the kill feed / toast is already gone, no clip is created. The original stays in the inbox.

Train and send

Trains an offline candidate only if both clean and suspicious clips exist. Path: data\models\candidates\. Not loaded live.

Spot-check clips, then send data\vod_dataset\. Do not commit videos to Git.

Troubleshooting

No popup? Watcher must be open first. Copy a new file into clean or cheating. Cancelled prompt: copy again with a new filename.
No clips? Check tag spelling. Bottom-left name and a kill indicator must be visible. Short highlight clips often need the feed still on screen.
Still processing? Keep the watcher open until the current video finishes.
