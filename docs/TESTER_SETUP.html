CHEATVISION · TESTER SETUP

Install once · Update from GitHub · Separate from the VOD how-to

setup.bat · update.bat
This sheet is install and update only. Drop-and-clip steps are on the VOD tester how-to. Inbox videos and extracted clips are not in git and stay on your PC.

1 · First time — setup.bat

  1. Install Python 3.11+ from python.org and tick Add python.exe to PATH.
  2. Clone the repo (needed later for updates):
    git clone https://github.com/SensoredRooster/CheatVision.git
  3. Open the CheatVision folder and double-click setup.bat.
  4. Answer the GPU and player-detector prompts. Y is the usual choice.

setup.bat creates .venv and installs the app, training extras, VOD OCR, ffmpeg if missing, and the optional player detector. You do not run pip yourself.

A ZIP works once. update.bat can pull GitHub changes only from a git clone.

2 · Later — update.bat

  1. Double-click update.bat whenever you want the latest from GitHub.
  2. It fast-forwards to origin/main.
  3. It refreshes app packages, training extras, and VOD OCR.
  4. Inbox videos and extracted clips are left untouched.

If the pull fails, local file changes may be in the way. Do not delete your clips. Tell the project owner.

3 · After setup or update

Start File
Live CheatVision app run.bat
VOD kill-clip watcher watch_vod_inbox.bat

If something looks missing, run .venv\Scripts\python.exe tools\setup_check.py.

Troubleshooting

Python not found? Reinstall Python, tick Add to PATH, then run setup.bat again.
Not a git clone? Clone the repo. ZIP folders cannot use update.bat.
Pull failed? Do not reset. Contact the project owner. Your clips were not deleted.
ffmpeg missing? Close this window, open a new one, then run ffmpeg -version.
