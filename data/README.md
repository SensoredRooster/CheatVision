# CheatVision dataset storage

Gameplay clips, labels, and notes for reviewing and (optionally) training.

## Structure

- `raw/` – original recordings before labeling
- `clean/` – confirmed clean gameplay
- `suspicious/` – flagged or labeled cheat clips
- `labels/` – per-clip notes
- `labels_template.csv` – import template
- `manifest.csv` – imported clip index
